# In-Class Examples

This directory contains small, self-contained examples used for in-class demonstrations in **FINM 33200: Generative and Agentic AI for Finance**.

These examples are designed to illustrate specific concepts during lectures without requiring their own dedicated repositories.

## Course Overview

FINM 33200 is a hands-on course covering the application of generative AI and agentic technologies in quantitative finance. The course emphasizes practical implementation using cutting-edge AI frameworks and tools.

### Main Topics

1. **AI Development Tools & Copilots** - Cursor, GitHub Copilot, AI-assisted workflows
2. **AI Tool Use & Agentic Workflows** - Claude Code, MCP servers, LangChain, LangGraph
3. **LLM Fundamentals** - Tokenization, tool use mechanics, challenges with financial data
4. **Retrieval-Augmented Generation (RAG)** - Vector databases, document processing, semantic search
5. **AI Application Development** - Next.js, Vercel, ChatKit, local vs. cloud deployment
6. **AI Governance & Evaluation** - Response quality, benchmarking, compliance for financial systems

### Tech Stack

- **Languages:** Python 3.12, TypeScript/JavaScript
- **AI Frameworks:** LangChain, LangGraph, OpenAI APIs
- **Web Development:** Next.js, Vercel, ChatKit
- **Vector Databases:** Pinecone, Milvus, Weaviate
- **Financial Data:** yfinance, edgartools, WRDS, xbbg
